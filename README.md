# Arena dos Jogos

Site com os 10 jogos mais jogados do mundo: números de jogadores, ficha de cada jogo, filtros e gráfico.

## Estrutura

```
arena-dos-jogos/
├── index.html      → estrutura da página (o "esqueleto")
├── css/
│   └── style.css   → aparência: cores, fontes, tamanhos
└── js/
    ├── dados.js    → informações dos jogos (edite aqui para mudar textos e números)
    └── script.js   → comportamento: cartões, filtros, ficha e gráfico
```

## Como rodar

1. Abra esta pasta no VS Code (Arquivo → Abrir Pasta).
2. Instale a extensão **Live Server** (Ritwick Dey).
3. Clique com o botão direito no `index.html` → **Open with Live Server**.

## Como publicar

Arraste a pasta inteira em https://app.netlify.com/drop (aba Deploys para atualizar).
